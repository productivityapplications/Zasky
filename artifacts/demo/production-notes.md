## What is real

- The transcript was generated by the real `openai/gpt-4o-mini` model through
  OpenRouter's OpenAI-compatible Chat Completions endpoint.
- The model called the real seven-tool surface. The reconcile proposal and the
  approval were applied by the real deterministic domain service.
- The numbers shown (270 min work, 1,066 min remaining budget, 16:00 etc.) come
  from the actual tool output and stored plan, not from a mockup.
- The demo DB is `data/demo.db`; it is synthetic and separate from any real
  personal plan.

## What is intentionally not shown

- No Discord screen capture. The host is headless and no test Discord session was
  authorized. The video is labeled **local protocol/transcript demo** throughout.
- No participant IDs, room IDs, hostnames, API keys, tokens or private URLs.
- No personal task titles or real owner data; all content is synthetic.

## Reproduce

```bash
cd /root/Zasky
uv run python scripts/seed_demo.py \
  --env-file /root/Zasky-secrets/zasky.env \
  --database-url 'sqlite+aiosqlite:////root/Zasky/data/demo.db' --reset
uv run python scripts/demo_transcript.py   # writes artifacts/demo/transcript.txt
uv run python scripts/build_demo_video.py  # writes the MP4 + narration script
```

`seed_demo.py` creates three goals, three commitments, three fixed events, six
week tasks and a Friday day plan. `demo_transcript.py` asks Friday-plan and
reconcile questions, approves the proposal code through the deterministic
domain, and queries the week. `build_demo_video.py` renders the slides and local
TTS.
